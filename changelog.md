# Changelog

All notable changes to the CCM Training Plugin Marketplace.

## [1.0.0] - 2026-04-03

### Added
- Initial marketplace with 4 educational plugins
- **code-quality** plugin: 3 skills (code-review, refactor-suggest, naming-conventions) demonstrating SKILL.md format, $ARGUMENTS, and multi-skill patterns
- **git-guardian** plugin: PreToolUse hook (blocks destructive git commands) + PostToolUse hook (logs file changes) + git-safety skill
- **team-standards** plugin: standards-enforcer agent + 2 supporting skills (check-standards, check-docs) + configurable settings.json
- **project-bootstrap** plugin: setup-wizard agent + scaffold-project skill + validate-structure skill + PostToolUse hook + settings.json — demonstrates all capabilities combined
- Comprehensive root README with installation instructions, learning path, plugin anatomy guide, and how-to-create-your-own guides
- marketplace.json with all 4 plugin entries
